如果你是零基础，想学会 CAD，我建议你按照 **“先学基础命令 → 学会看图 → 模仿画图 → 独立画图”** 这个顺序来。

**每天学习1小时，坚持30天，通常就能掌握CAD二维绘图的基本操作，并尝试独立完成简单图纸。**

下面给你一套适合零基础的学习路线。这里先以最常见的 AutoCAD 为例。

## 一、先搞清楚：CAD主要学什么？

CAD是一类计算机辅助设计软件，AutoCAD是其中一种，常用于：

- 机械设计：零件图、装配图
- 建筑设计：建筑平面图、立面图
- 室内装修：户型图、家具布置图
- 电气设计：电路图、电气施工图
- 工程施工：各种施工图纸

如果你完全没有基础，**建议先学二维绘图，暂时不要碰三维建模。**

因为二维绘图是理解CAD操作的重要基础。

## 二、第一阶段：熟悉CAD界面（第1～3天）

刚开始不要急着画复杂的图。

先了解以下内容：

1. CAD软件如何打开和新建图纸。
2. 鼠标滚轮如何放大、缩小图纸。
3. 如何移动绘图视图。
4. 如何使用命令输入框。
5. 如何保存DWG格式文件。
6. 如何设置绘图单位。

还要掌握几个重要操作：

| 操作 | 快捷键 |
|---|---|
| 取消当前命令 | Esc |
| 撤销操作 | Ctrl+Z |
| 保存图纸 | Ctrl+S |
| 开启或关闭正交模式 | F8 |
| 开启或关闭对象捕捉 | F3 |
| 重复上一条命令 | 空格或回车 |

**这一阶段的目标：** 能熟练操作软件界面，不再觉得CAD复杂。

## 三、第二阶段：掌握常用绘图命令（第4～10天）

这是CAD学习最重要的阶段。

先掌握下面这些命令：

### 1. 基础绘图命令

| 快捷命令 | 功能 | 重要程度 |
|---|---|---|
| L | 直线 | ⭐⭐⭐⭐⭐ |
| C | 圆 | ⭐⭐⭐⭐⭐ |
| REC | 矩形 | ⭐⭐⭐⭐⭐ |
| PL | 多段线 | ⭐⭐⭐⭐ |
| A | 圆弧 | ⭐⭐⭐ |
| H | 图案填充 | ⭐⭐⭐⭐ |

刚开始可以练习画：

- 正方形
- 长方形
- 圆形
- 三角形
- 简单几何组合图

### 2. 修改编辑命令

| 快捷命令 | 功能 | 重要程度 |
|---|---|---|
| M | 移动 | ⭐⭐⭐⭐⭐ |
| CO | 复制 | ⭐⭐⭐⭐⭐ |

**学习技巧：每学会一个命令，立即动手操作10遍。**

不要只看视频，因为看懂和会操作完全是两回事。

## 四、第三阶段：学习精确绘图（第11～17天）

CAD最重要的特点是：**尺寸必须准确。**

这个阶段重点学习：

1. 坐标输入
2. 正交模式
3. 对象捕捉
4. 图层管理
5. 尺寸标注
6. 文字标注
7. 线型与线宽

例如：

你需要画一个长100毫米、宽60毫米的长方形。

不能随便用鼠标拖出一个大概的形状。

而是要通过命令准确输入尺寸。

然后再画一个直径20毫米的圆，并将它放在长方形中心。

最后添加尺寸标注。

当你能独立完成这些操作，就已经具备基本的CAD绘图能力了。

## 五、第四阶段：开始练习实际图纸（第18～25天）

这个时候不能一直画圆形、矩形了。

要开始接触真实图纸。

可以根据自己的学习方向选择。

**如果想学机械CAD：**

建议依次练习：

1. 简单垫片
2. 带孔连接板
3. 轴类零件
4. 法兰盘
5. 简单机械零件图

**如果想学建筑CAD：**

建议依次练习：

1. 单个房间平面图
2. 简单户型图
3. 门窗绘制
4. 墙体绘制
5. 建筑平面图

**如果想学室内设计CAD：**

建议依次练习：

1. 卧室平面图
2. 客厅家具布置图
3. 两室一厅户型图
4. 家具尺寸标注
5. 完整室内平面布置图

这个阶段的关键是：

**找一张有尺寸的图纸，先照着画，再尝试不看教程独立画出来。**

## 六、第五阶段：掌握完整出图流程（第26～30天）

学CAD不仅要会画图，还要会把图纸整理好。

最后5天主要学习：

- 图层分类和管理
- 尺寸标注样式
- 文字样式
- 图框和标题栏
- 图纸比例
- 布局与打印
- 导出PDF文件

最终目标是：

能够从新建文件开始，独立完成一张包含图形、尺寸、文字和图框的规范二维图纸，并正确输出。

这也符合 Autodesk 官方的入门课程顺序：从基础几何图形、精确绘制，到图层、标注、图块和布局输出。

官方学习资料：

- [AutoCAD官方零基础教程](https://www.autodesk.com/learn/ondemand/collection/get-started-with-autocad)
- [AutoCAD官方二维绘图指南](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-GettingStarted/files/GUID-2AA12FC5-FBB2-4ABE-9024-90D41FEB1AC3.htm)

## 七、零基础学习CAD，最容易犯的4个错误

**错误1：只看视频，不动手**

看10个小时视频，不如自己实际画3个小时。

建议学习时间这样分配：

- 20分钟看教程
- 40分钟自己操作

**错误2：一开始就学复杂图纸**

先从简单图形开始，再练习复杂图纸。

**错误3：死记所有快捷命令**

不用一次记住几十个命令。

先熟练掌握10～15个高频命令，再逐渐增加。

**错误4：只学软件，不学识图**

CAD只是一种绘图工具。

如果想真正用于工作，还需要学习机械制图、建筑识图或相应专业的制图规范。

## 八、我建议你这样开始

如果你今天刚开始学CAD，第一天只需要完成4件事：

1. 安装并打开CAD软件。
2. 学会鼠标缩放和移动视图。
3. 使用 `L` 命令画直线。
4. 使用 `REC` 命令画一个100×60的矩形。

完成以后再学习画圆、复制、偏移和修剪。

不要着急，循序渐进就可以。
