本页是原 Python 项目的浏览器 / B站 Toy 移植版。推理代码改写为 JavaScript，界面重新实现；原模型权重未修改，继续使用原作的标准化、字符特征、虚词骨架、逻辑回归、概率校准、长文分段与十条文风规则。原作代码采用 MIT 许可，模型采用 CC BY-SA 4.0 许可。本移植版代码同样采用 MIT，模型继续采用 CC BY-SA 4.0。

模型与训练数据署名

原始模型文件：aiqiang/model.json，版本 1，创建于 2026-11-15。网页构建产物仅在文件名添加内容指纹，文件内容保持原样。模型依据原作声明采用 知识共享署名-相同方式共享 4.0 国际许可（CC BY-SA 4.0）。训练来源如下，署名沿用原项目 README：

来源许可内容

人类原文没有打入本页。原作仅用于评测的中学生作文、微博及其他问答数据不属于本页训练权重的数据输入；完整数据说明保留在项目 README 中。

结果的适用范围

这把尺子只量文风，不能证明作者身份。原作报告的测试成绩属于原数据集，不能视为现实文本的准确率承诺。短文、平实的百科科普、新闻、改写、人机合写、繁体中文与训练范围外的体裁都可能不可靠；AI 模型迭代也会影响结果。三家倾向只在 DeepSeek、GPT、Claude 之间比较，其他模型也会被分到这三类之一。“AI 八股”命中机会随文本长度增加，只适合比较长度相近的文字。不要拿结果指控他人，尤其是学生。

分析时仅从本站加载静态代码与模型，输入文字不会发送给服务器，不使用云存储或本地持久化。页面加载和外部链接仍需要网络。非 Anthropic、OpenAI、DeepSeek 官方产品。
